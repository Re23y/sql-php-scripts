# SQL PHP Scripts
This repository contains the PHP scripts I used for my cloud-based SQL only database project. The Redis implementation scripts are in a separate repository.
These scripts with my other repository contents from the project should enable anyone to imitate my project, with setup. 

# PHP Setup
Within the four provided PHP scripts you must change the following values:
- $host = 'hostname'; // Replace with your actual host name
- $db = 'dbname';     // Replace with your actual database name
- $user = '';         // Replace with your actual username
- $pass = '';         // Replace with your actual password

Once you have ensured these are all correct they should work.
